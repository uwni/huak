# CLI 进程对比

`bench-compare` 对两个已构建的 CLI 使用相同参数，每次启动独立进程：

```sh
zig build bench-compare -Doptimize=ReleaseSafe -- ./huak-before ./huak-after cases.json > results.json
```

`cases.json` 列出负载名称、完整 CLI 参数及需比较的生成文件。例如：

```json
[
  {
    "name": "drawing",
    "args": ["run", "examples/language/drawing.huak", "--output=target/compare.svg"],
    "outputs": ["target/compare.svg"]
  }
]
```

路径相对于运行目录；无输出的负载可省略 `outputs`。每次运行前删除清单中的生成文件，运行后比较 SHA-256，避免误用旧产物。进程失败、缺少输出或产物变化都会使对比失败，子进程日志在 `target/compare-child.log`。

每项负载执行 2 轮预热和 16 轮交替顺序的配对测量。JSON 保存二进制路径和哈希、参数、原始样本、中位数与配对差值的 95% t 区间。耗时包含进程启动和退出；RSS 是子进程峰值驻留内存，不是分配器申请峰值。输出哈希检查在计时外执行。

比较时固定编译器、编译选项、输入和 libtypst，并保存这些来源记录。先将同一二进制同时作为 before/after 检查测量波动；短负载或多项比较的单个区间不能独立证明回退。工具不自动作验收结论。

## 动态笔尖

`zig build bench-pen-motion -Doptimize=ReleaseFast` 测量从连续扫掠到返回轮廓的耗时。中心线是一条横跨 100 pt 的三次 Bézier，圆笔直径按 2 → 12 → 1 pt 变化，7 × 3 pt 的矩形笔尖则按 `1 + t²` 横向缩放并旋转 2.2 rad。每个组合构造五次独立的轮廓，记录中位耗时与输出路径段数。计时不含解释器、原生排版或文件输出。最后一次构造完成后，对路径指令及其 binary64 坐标求哈希，供同平台构建比较。

局部区间内，笔尖的一条边和它的运动构成双线性映射。其雅可比行列式在参数方形内为一次式；零线映射成二次 Bézier，再升阶写入 Huak 的三次路径。相邻面上相抵的有向边先抵消，留下的候选边界一起按非零绕数整理。曲线中心线、椭圆笔尖及非线性运动各有空间误差预算。测试包含已知抛物线包络、增长圆盘公切线、整圈旋转、独立矩形包含判定与精度不足时报错。有关扫掠包络的奇异集合方法，可参阅[平面扫掠体与 Minkowski 和的代数构造](https://www.sciencedirect.com/science/article/abs/pii/S0167839622000437)。

2026-11-05 在 macOS arm64、Zig 0.17.1 ReleaseFast 上测得以下结果。全量测试结束后单独运行已构建的基准程序。

| 笔尖运动 | 几何容差 | 中位耗时 | 输出路径段数 |
| --- | ---: | ---: | ---: |
| 圆笔变宽 | 0.02 pt | 1.371 ms | 665 |
| 圆笔变宽 | 0.001 pt | 12.166 ms | 3074 |
| 矩形笔缩放并旋转 | 0.02 pt | 4.445 ms | 524 |
| 矩形笔缩放并旋转 | 0.001 pt | 225.083 ms | 2700 |

同日 ReleaseSafe 全量构建与测试完成 90/90 步，本轮实际运行 1281 项测试。CLI 验收完成 430 个子进程。用原生 libtypst 导出 `examples/language/erase.huak`，1 和 4 个 worker 生成的 SVG、PDF 分别逐字节一致。另用 100 pt 坐标、0.0000001 pt 导出容差验证 `OutputPrecisionRange`，用严重消去的缩放表达式验证 `PrecisionRange`。

### 0.001 pt 旋转笔的耗时分布

2026-11-06 在同一台 macOS arm64 机器上，用 Zig 0.17.1 ReleaseFast 对照 `dc79573`。首次复测总计 224.22 ms，其中 0.97 ms 生成有向包络，223.25 ms 用于布尔整理及返回。原版进程的 700 个 CPU 样本中，697 个位于布尔运算，675 个位于布尔建图。

下表来自随后同机串行的六轮配对测量。每轮交换新旧版本的先后顺序，每个进程测五次并取中位数，再取六轮中位数。前两行在 `regions.combine` 调用前插入时间戳，第三行来自移除计时和计数探针的独立构建。工作量按单次构造统计。

| 矩形笔缩放并旋转，0.001 pt | 优化前 | 优化后 |
| --- | ---: | ---: |
| 构造有向包络 | 0.685 ms | 0.675 ms |
| 布尔整理及返回 | 157.80 ms | 39.60 ms |
| 显式轮廓总耗时（无探针） | 157.92 ms | 39.78 ms |
| 逐段检查的候选顶点（含前缀端点检查） | 68,923,306 | 681,104 |
| 曲段最近点查询 | 114,189 | 21,615 |
| 接受的补充切分 | 18,603 | 18,603 |

优化后的建图按原曲线较长的坐标轴索引候选顶点。先从候选序列前端移除曲段自身端点，仍有候选时才构造该段曲线。用它的控制点包围盒查询索引，再用四个控制点在弦法线上的投影排除过远顶点。余下的点按原顶点编号判定，确保多个点都满足容差时采用同一切分。

四个笔尖基准的路径指令及坐标哈希逐项吻合，精细旋转笔保持 2700 条指令，哈希为 `cc661091a23ed55e`。同批无探针基准中，0.02 pt 旋转笔从 3.160 ms 降到 1.758 ms。圆笔在 0.02 pt 时为 0.848 → 0.786 ms，在 0.001 pt 时为 8.783 → 8.769 ms。

通用布尔基准的 21 个用例均通过覆盖检查。256 个曲线孔洞的六轮中位数为 577.40 → 572.68 µs。对短用例增加到每轮五次、每次两千个操作后，共边矩形为 5.210 → 5.149 µs，半个三次曲线的差集为 6.305 → 6.373 µs。

另对这条旋转笔迹比较了两种填充表示。扫掠直接给出 2900 条有向路径指令，布尔整理后为 2700 条。两份路径以 0.0000001 pt 展平，在 19,712 个位置按非零绕数检验，覆盖结果全部相同。该实验只比较几何覆盖，未计 SVG/PDF 后端的填充时间。生产绘图和擦除仍使用显式轮廓。

索引和投影筛选通过 ReleaseSafe 全量测试（90/90 步，1283/1283 项，含 430 个 CLI 子进程验收）。加入端点前置筛选后，最终版本通过几何、布尔、笔尖与原生渲染专项（47/47 步，376/376 项）。用最终 CLI 与原生 libtypst 导出 `examples/language/erase.huak`，SVG 和 PDF 与优化前的对应文件逐字节一致。

同日清理布尔内核的未用函数，并让静态和动态笔尖复用轮廓整理后，377 项专项测试和 21 个布尔基准用例通过。与清理前的二进制交替运行六轮，四组笔尖的路径指令数及坐标哈希逐项相同，0.001 pt 旋转笔的六轮中位耗时为 38.82 → 37.24 ms。`erase.huak` 的 SVG 和 PDF 与清理前逐字节相同。
